About This App

This Todo App helps users manage daily tasks efficiently. Users can add, update, delete, search, and mark tasks as completed.

Key Features
  • Add, update, and delete tasks
  • Mark tasks as completed
  • Search tasks easily
  • Simple and clean interface
Technologies Used
  • Python & Flask
  • SQLAlchemy & SQLite
  • HTML, CSS, Bootstrap
Purpose

This project was built to practice backend development concepts such as CRUD operations and HTTP methods.
